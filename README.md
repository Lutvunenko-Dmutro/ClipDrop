# 🎬 ClipDrop — Універсальний Telegram Медіа-Бот

![Python](https://img.shields.io/badge/python-3.10+-blue.svg)
![aiogram](https://img.shields.io/badge/aiogram-3.15-2BA86D.svg)
![yt-dlp](https://img.shields.io/badge/yt--dlp-latest-red.svg)
![GitHub Actions](https://img.shields.io/badge/CI%2FCD-GitHub%20Actions-2088FF.svg)

**ClipDrop** — це потужний, швидкий та сучасний Telegram-бот, який вміє не лише завантажувати медіафайли з найпопулярніших платформ (**YouTube** та **TikTok**), але й має вбудовану систему **інлайн-пошуку аудіо-мемів** на базі штучного інтелекту. 
Бот побудований на асинхронному фреймворку `aiogram 3.x`, підтримує безперервне розгортання (CI/CD) та стійкий до блокувань дата-центрів.

---

## ✨ Основні можливості

### 🎵 Медіа-завантажувач (Відео)
- **TikTok:** Миттєве завантаження відео в найкращій якості (автоматично розпаковує короткі посилання `vm.tiktok.com`).
- **YouTube (RapidAPI):** Використовує стороннє API для швидкого завантаження відео, обходячи блокування IP-адрес від YouTube для хмарних серверів (Render/AWS). Бот відображає прогрес конвертації відео в реальному часі.
- **YouTube Fallback (yt-dlp):** Якщо ліміт API вичерпано, бот автоматично переключається на локальне завантаження через `yt-dlp`.
- **Авто-стиснення (FFmpeg):** Якщо відео важить понад 50 МБ (ліміт Telegram API), бот автоматично стискає його за допомогою `ffmpeg`, щоб ви все одно отримали свій файл.

### 🎙 Інлайн-пошук мемів (MyInstants)
- **Розумний перекладач:** Завдяки інтеграції з `deep-translator` (Google Translate), ви можете писати запити українською або російською мовою, а бот автоматично знайде англомовні меми.
- **Fuzzy Search (Нечіткий пошук):** Якщо ваша фраза занадто довга, бот розбиває її на слова та шукає паралельно всі можливі варіанти, щоб завжди знайти крутий звук.
- **Маскування Cloudflare:** Бот успішно обходить блокування Cloudflare, маскуючись під звичайний браузер.

### ⚙️ Архітектура та Безпека
- **CI/CD Pipeline (GitHub Actions):** Будь-який пуш у гілку `main` автоматично перевіряє код на помилки (CI) і розгортає його на серверах Render (CD) за допомогою `RENDER_DEPLOY_HOOK_URL`.
- **Zero-Trace (Очищення):** Бот автоматично видаляє файли з сервера одразу після відправки в Telegram, не забиваючи дисковий простір.
- **Режим Webhook:** Оптимізовано для Render — миттєві відповіді та економія ресурсів. Інтегровано перевірку за допомогою `WEBHOOK_SECRET` для захисту від зловмисних запитів.
- **Anti-Flood та Ліміти:** Вбудований захист від спаму з денними лімітами для звичайних користувачів та режимом Бога (`OWNER_ID`) для розробника.

## 🛠 Змінні оточення (.env)

Для роботи бота необхідно створити файл `.env` у корені проєкту (або додати їх у панелі Render):

```env
# Токен вашого Telegram-бота (отримайте у @BotFather)
TOKEN=your_telegram_bot_token

# Ключ від YouTube Video FAST Downloader 24/7 (RapidAPI)
RAPIDAPI_KEY=your_rapidapi_key

# Ваш Telegram user_id (без обмежень для власника бота)
OWNER_ID=your_telegram_user_id

# Публічна URL-адреса вашого сервера (для Webhook режиму)
# Наприклад: https://your-service.onrender.com
WEBHOOK_URL=https://your-service.onrender.com

# Секретний ключ для захисту Webhook (будь-який складний пароль)
WEBHOOK_SECRET=MySuperSecretToken123
```

## 🚀 Встановлення та запуск (Локально)

1. **Встановіть залежності системи:**
   Переконайтеся, що у вас встановлено Python 3.10+ та **FFmpeg**. 
   - На Windows: завантажте з офіційного сайту та додайте в PATH.
   - На Linux: `sudo apt install ffmpeg`

2. **Встановіть Python-бібліотеки:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Створіть `.env` файл** (див. розділ вище).

4. **Запустіть бота:**
   ```bash
   python main.py
   ```
   *(Без WEBHOOK_URL бот автоматично запуститься в режимі Polling).*

## ☁️ Автоматичний Деплой (Render + GitHub Actions)

Проєкт налаштований для безперервного розгортання (CI/CD) на [Render.com](https://render.com/).

1. Зробіть **Fork** або завантажте цей репозиторій на свій GitHub.
2. Створіть новий **Web Service** на Render з середовищем `Docker`.
3. У розділі **Environment Variables** додайте всі змінні з `.env`.
4. Знайдіть у Render розділ **Deploy Hook** та скопіюйте його.
5. Перейдіть у налаштування вашого репозиторію на GitHub: **Settings -> Secrets and variables -> Actions**.
6. Створіть новий секрет з назвою `RENDER_DEPLOY_HOOK_URL` і вставте скопійоване посилання.

Тепер при кожному `git push` GitHub автоматично перевірятиме код і командуватиме Render-у оновити бота!
