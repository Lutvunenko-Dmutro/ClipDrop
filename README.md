# Universal Telegram Media Downloader

Потужний і сучасний Telegram-бот для завантаження відео з **YouTube** та **TikTok**. 
Написаний на базі `aiogram 3.x` з використанням `yt-dlp` та `ffmpeg`.

## Можливості 🚀
- 🎵 **TikTok:** завантаження прямих відео (швидко і без водяних знаків, якщо доступно). Розпаковує короткі посилання (vm.tiktok.com).
- 📺 **YouTube:** завантаження відео в найкращій якості.
- 🗜 **Авто-стиснення:** якщо відео з YouTube важить понад 50 МБ (ліміт Telegram), бот автоматично використовує `ffmpeg`, щоб стиснути його і все одно надіслати вам.
- 🧹 **Очищення:** бот автоматично видаляє файли з сервера після відправки, не забиваючи диск.

## Встановлення (Локально)

1. Встановіть Python 3.10+ та `ffmpeg`.
2. Встановіть залежності:
   ```bash
   pip install -r requirements.txt
   ```
3. Створіть файл `.env` на основі `.env.example` та вкажіть ваш `TOKEN`.
4. Запустіть бота:
   ```bash
   python main.py
   ```

## Встановлення (Docker)

Найпростіший спосіб розгорнути бота на сервері:

```bash
docker build -t media-bot .
docker run -d --name my-media-bot --env-file .env media-bot
```
